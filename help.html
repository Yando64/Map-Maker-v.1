Help & Tutorial

Quick Start

  1. Open Tactical Map in your browser.
  2. Choose a symbol from the left toolbar (e.g. Infantry under Friendly Units).
  3. Click anywhere on the map to place the symbol. The cursor changes to a crosshair in Place mode.
  4. Click the Select tool (or press S) to switch back to move/edit mode.
  5. Click a placed symbol to open its Properties panel and set a callsign, echelon, and notes.
  6. Use Save Overlay (or Ctrl+S) to download a JSON file of your work.

Placing Symbols

Select any symbol type from the toolbar. The toolbar is organized into sections: Friendly Units (blue), Enemy Units (red), Neutral / Unknown (amber / purple), and Tactical Lines. Clicking a symbol button activates Place mode for that symbol type. Each subsequent click on the map places another symbol of the same type. Press Escape or S to return to Select mode.

Symbols automatically scale with the map zoom level — they appear larger at higher zoom levels so they remain readable relative to the terrain features beneath them.

Moving & Editing Symbols

In Select mode, you can:

  • Drag any symbol to reposition it on the map.
  • Click a symbol to open the Properties panel on the right.
  • Right-click a symbol for a context menu with Edit, Duplicate, Copy MGRS, and Delete options.

In the Properties panel you can set the unit's callsign / label, echelon, affiliation, higher headquarters, and free-text notes. Click Apply to save changes.

Drawing Lines and Areas

Select a line type from the Tactical Lines section of the toolbar. This activates Draw Line mode. Click the map to place waypoints one at a time. Double-click the final point (or press Enter) to finish the line. Press Escape to cancel a line in progress.

Saving and Loading Overlays

All data is stored in a simple JSON format. Use the Map Tools section at the bottom of the toolbar to save and load:

  • Save Overlay — prompts for a name, then downloads a .json file.
  • Load Overlay — opens a file picker to load a previously saved .json.
  • GitHub Overlays — fetches an index from the repository's /overlays/ folder and lets you load shared overlays directly.

Loading an overlay adds to whatever is already on the map. Use Clear All first if you want to start fresh.

Exporting Your Map

  • Export PNG — captures the visible map area as a PNG image.
  • Export PDF — creates a landscape A4 PDF with the map and a unit legend.
  • Export GeoJSON — exports all units and lines as standard GeoJSON, compatible with QGIS, ArcGIS, and other GIS tools.
  • Export KMZ — exports a KMZ file compatible with Google Earth.

MGRS Coordinate System

The Military Grid Reference System (MGRS) divides the world into Grid Zone Designators (GZDs), then into 100km squares identified by two letters, then into numeric grid coordinates. A full 10-digit MGRS reference (5 digits easting + 5 digits northing) identifies a 1-meter square.

Example: 18S UJ 12345 67890

  • 18S — Grid Zone Designator
  • UJ — 100km square identifier
  • 12345 — Easting (5 digits = 1m precision)
  • 67890 — Northing (5 digits = 1m precision)

The MGRS Grid overlay (toggle via the layer control top-right) draws grid lines on the map. The grid density adjusts automatically with zoom level — 100km zones at low zoom, down to 100m squares at high zoom.

FAQ

Is my data stored anywhere online?

No. All data stays in your browser. Nothing is sent to any server. Overlays are downloaded as files to your computer.

Can I share an overlay with others?

Yes — share the downloaded JSON file. The recipient can load it using Load Overlay. If the repository owner adds overlays to the /overlays/ folder, they will appear in the GitHub Overlays list.

Why don't symbols appear when I zoom out too far?

Symbols scale proportionally with zoom. At very low zoom levels (<4) they become very small but are still present. Zoom in to a region of interest before placing symbols.

Can I change a symbol's affiliation after placing it?

Yes — click the symbol to open its Properties panel, change the Affiliation dropdown, and click Apply. The frame color and shape will update immediately.

Does this work offline?

The app itself works offline once loaded (for symbol placement, editing, and export). Map tiles require an internet connection. GitHub Overlays also require connectivity.
